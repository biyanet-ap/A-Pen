# A-Pen

[English](README.md) | [한국어](README.ko.md) | **日本語**

オンライン授業や教室での授業のための Windows 用ペンアプリです。発表画面の上に直接書き込んだり、ボードに切り替えて板書したり、板書を保存しておいて次の授業で開き直したりできます。ワコムなどのペンタブレット、マウス、電子黒板で使えます。

バージョン 1.0.0 · Windows 10/11 · [MIT License](LICENSE) · [HighPen](https://github.com/stepanowon/high-pen) ベース

![A-Pen でスライドに書き込んだ画面](screen/hero.jpg)

## インストール

1. [最新リリース](https://github.com/biyanet-ap/A-Pen/releases/latest) から **[A-Pen-Setup.exe](https://github.com/biyanet-ap/A-Pen/releases/latest/download/A-Pen-Setup.exe)** をダウンロードします。
2. 実行します。**「Windows によって PC が保護されました」** と表示されたら、**詳細情報 → 実行** を押します。（ファイルにコード署名がないために表示される警告です。）
3. 3 つの質問に答えます。インストールするか、デスクトップにショートカットを作るか、今すぐ起動するかです。

A-Pen は `%LOCALAPPDATA%\Programs\A-Pen` にインストールされ、スタートメニューに追加されます。管理者権限は不要です。

- **インストールせずに使う:** [A-Pen.exe](https://github.com/biyanet-ap/A-Pen/releases/latest/download/A-Pen.exe) をダウンロードしてそのまま実行します。
- **更新:** 新しいインストーラーを実行すると上書きされます。
- **アンインストール:** 設定 → アプリ → **インストールされているアプリ** → A-Pen → アンインストール。設定は `%APPDATA%\A-Pen` に残るので、完全に消すにはこのフォルダーも削除します。
- **質問なしでインストール:** `A-Pen-Setup.exe /S`
- **スマート アプリ コントロール:** Windows 11 のスマート アプリ コントロールがオンだと、署名のないファイルは「実行」の選択肢なしでブロックされます。A-Pen を使うにはスマート アプリ コントロールをオフにする必要があります（Windows セキュリティ → アプリとブラウザー コントロール）。2026 年 4 月の Windows 更新（KB5083769）がないと一度オフにしたあとオンに戻せないため、先に Windows を更新してください。

ツールバーは画面の左上に英語で表示されます。**Settings** を押して **Language** で **日本語** を選ぶと、すぐに切り替わります。

## 機能

| 機能 | できること |
|---|---|
| **ペン** (Pen) | 画面のどこにでも書き込めます。ペンをオフにすると、書き込みを残したまま発表資料をめくれます。8 色、太さ 1〜30、筆圧に対応。 |
| **ボード** (Board) | 画面をボードで覆います。**緑 → 白 → 黒 → オフ** の順に切り替わります。ボードごとにページを持てます（`◀ 2/5 ▶`、**＋** で新しいページ、ゴミ箱で削除）。ボードの色に埋もれるペンの色は自動で変わります。 |
| **消しゴム** (Eraser) | 黒板消しのように、こすった部分だけを消します。大きさ 10〜150。 |
| **範囲** (Area) | ドラッグした四角形の中をまとめて消します。 |
| **全消去** (Clear) | 今のページをすべて消します。 |
| **元に戻す / やり直し** (Undo / Redo) | 1 段階ずつ取り消したり、もう一度適用したりします。ページごとに別々に動きます。 |
| **吹き出し** (Note) | 入力した文字を枠付きの箱にして貼ります。 |
| **キャプチャ** (Capture) | 使用モニターの画面をデスクトップに PNG で保存します。ツールバーとマウススポットは写りません。 |
| **開く** (Open) | 画像をボードの新しいページとして開き、続けて書き込めます。 |
| **拡大** (Zoom) | ポインターのまわりを 1.5 倍・2 倍・2.5 倍に拡大します。拡大したまま書き込めます。 |
| **スポット** (Spot) | ポインターについて動く半透明の円で、見ている人がポインターを見つけやすくなります。 |
| **モニター** (Monitor) | モニターが 2 台以上あれば、A-Pen を使うモニターをツールバーで選べます。 |

設定（ペン、消しゴム、スポット、拡大倍率、モニター、言語）は変更するとすぐに `%APPDATA%\A-Pen\settings.txt` に保存されます。

## 電子黒板で使う

1. 電子黒板の **タッチ用に組になっている HDMI 端子** と **USB タッチ端子** を一緒につなぎます。HDMI だけでは画面は映りますが、タッチは使えません。
2. Windows の設定 → システム → バージョン情報 の「ペンとタッチ」にタッチ ポイントが表示されることを確認します。
3. 電子黒板を触るとノートパソコンの画面が反応する場合は、`tabletpc.cpl` → **画面** タブ → **セットアップ** → **タッチ入力** を選び、案内が出たら電子黒板をタッチします。
4. A-Pen のツールバーのモニターの行で、電子黒板の画面の番号を選びます。

## 自分でビルドする

Visual Studio や .NET SDK は不要です。Windows に入っている C# コンパイラーでビルドします。

```powershell
.\build.ps1    # dist\A-Pen.exe と dist\A-Pen-Setup.exe を作ります
```

## 元の HighPen

A-Pen は StephenWon 氏が MIT License で公開している **[HighPen](https://github.com/stepanowon/high-pen)** をもとに作成しました。原作者に感謝します。

![原作の表示がある情報ウィンドウ](screen/about.png)

**A-Pen で追加したもの**

- 緑ボード、ボードごとの複数ページ
- こすった部分だけを消す消しゴム（大きさ調整あり）、範囲消去
- やり直し
- 画面キャプチャの保存、キャプチャをボードのページとして開く
- ツールバーからのモニター選択
- 新しいツールバーのデザインとアプリのアイコン

**HighPen との違い**

- 名前、インストール先、設定フォルダーが異なるので、HighPen と一緒にインストールして同時に実行できます。
- winget と Microsoft Store の HighPen は元のアプリなので、上の機能はありません。
- 原作の著作権表示は [LICENSE](LICENSE) にそのまま残しています。
